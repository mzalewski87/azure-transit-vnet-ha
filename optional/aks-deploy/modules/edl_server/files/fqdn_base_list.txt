# AKS Egress FQDN Baseline
#
# Hardcoded fallback list used by generate_aks_edl.py when the dynamic update
# from Microsoft docs/APIs fails. Sourced from:
#   https://learn.microsoft.com/en-us/azure/aks/outbound-rules-control-egress
#
# Format: one FQDN per line. Wildcards permitted. Lines starting with # or
# ; are comments. The ${REGION} placeholder is substituted at generation
# time with the value of aks_region from settings.yaml.
#
# NOTE: trailing slashes are NOT included here — the generator appends "/"
# to every non-comment line when writing aks-egress-fqdn.txt. PAN-OS URL EDL
# requires the trailing slash for wildcard matches to work.
#
# Re-read the MS docs page when you suspect missing endpoints; categories
# below mirror the structure of that page so cross-checks are mechanical.

# --- Required: AKS control plane + Azure global ---
*.hcp.${REGION}.azmk8s.io
mcr.microsoft.com
*.data.mcr.microsoft.com
mcr-0001.mcr-msedge.net
# MCR data path actually downloads from *.blob.core.windows.net (Azure Storage
# CDN); without this, PAN-OS sees the traffic as azure-storage-account and the
# URL category match fails because there's no blob.core.windows.net entry.
*.blob.core.windows.net
management.azure.com
login.microsoftonline.com
packages.microsoft.com
acs-mirror.azureedge.net
packages.aks.azure.com
